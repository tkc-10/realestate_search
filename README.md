# 不動産投資物件トラッカー

楽待・健美家の物件情報を定期的に収集し、掲載動向を分析するツールです。

## 機能

- **物件追跡**: 検索URLを登録するだけで、物件の初回確認日・最終確認日・掲載日数を自動記録
- **売れ行き分析**: 掲載が消えた物件（売却・削除）を検知し、何日で売れたかを記録
- **定期スクレイピング**: 設定した間隔（3h/6h/12h/24h）で自動実行
- **物件フィルタリング**: サイト・都道府県・物件種別・利回り・価格で絞り込み
- **分析ダッシュボード**: 掲載日数分布、早く売れた物件の特徴を可視化
- **変更履歴**: 価格・利回りの変化を時系列で記録

## セットアップ

```bash
# 1. 依存パッケージをインストール
# Mac/Linux
pip3 install -r requirements.txt
# Windows
pip install -r requirements.txt

# 2. Playwright用ブラウザをインストール
playwright install chromium

# 3. 起動
# Mac/Linux
python3 run.py
# Windows
python run.py
```

ブラウザで http://localhost:8000 が自動的に開きます。

## 使い方

1. **検索条件を追加**: 「検索条件」ページで各サイトの検索URLを登録
   - 楽待やの検索画面で条件を設定し、そのURLをコピーして貼り付け
   - 実行間隔と取得ページ数を設定

2. **スクレイピング実行**: 「今すぐ実行」で手動実行、または自動スケジュール待ち

3. **物件確認**: 「物件一覧」でフィルタリング、個別物件の詳細・履歴を確認

4. **分析**: 「分析」ページで市場動向・早売れ物件の特徴を確認

## 注意事項

- 各サイトの利用規約を遵守してください
- サーバーへの過度な負荷を避けるため、間隔は6時間以上を推奨します
- スクレイパーのCSSセレクタはサイトのHTML構造変更で動作しなくなる場合があります
  - `app/scrapers/rakumachi.py` / `app/scrapers/kenbiya.py` を適宜修正してください

## データベース

SQLiteファイル (`realestate.db`) がプロジェクトルートに自動作成されます。

## スクレイパーのカスタマイズ

サイトのHTML構造が変わった場合、各スクレイパーファイルのCSSセレクタを更新してください:

- `app/scrapers/rakumachi.py` - 楽待
- `app/scrapers/kenbiya.py` - 健美家
